Android POS 화면 목업 (spec 001 T14)

시뮬레이터 specs/001-pos-beacon-simulator/ui-mockup.html의 3패널 배치를 그대로 두고 Android Peripheral에서 달라지는 것만 바꿨다. 값은 전부 예시. 구현은 Compose(ui/MainScreen·MainViewModel).

412×900 세로 폰 기준. ①②는 고정, ③이 남은 높이를 차지해 스크롤한다. 탭과 행을 눌러볼 수 있다.

수신 이벤트 한 행 = 접속 · 멤버 ID · UWB1줄: 시각 · 세션 라벨 · 주소(축약)+MTU · 판정 배지 · 연결→write 경과(elapsed_s, D-003). 2줄: 멤버 ID(굵게) · UWB 주소(미지원이면 흐리게) · nonce. 3줄: 조회 결과·마스킹 이름·전달 방식(notify/READ), 사이클이면 cycle k · 광고 시작 후 N.Ns. events CSV 17열이 그대로 재료다.
행을 탭하면 상세접속 정보(주소 전체·연결 시각·MTU·구독), raw 16B 필드 색, nonce 발급↔수신 대조, result JSON, 전달(NOTIFY 크기와 MTU−3 한도). 한 번에 한 행.
② 연결 중인 폰 — 열이 늘었다 (FR-18)세션 라벨 · 멤버 ID+주소+연결 경과 · UWB · 링크(MTU·구독). 시뮬레이터는 멤버 ID·UWB 두 열이었지만 Android는 onMtuChanged·CCCD를 알므로 NOTIFY 가능 여부를 점원이 바로 본다. payload 전 연결도 보인다. 우리 서비스를 안 쓰는 central도 라벨을 소비한다(§F-6) — 그대로 보여 준다.
① 배지 세 개 · 입력 여섯 · 버튼 세 개광고 배지에 콜백이 돌려준 실제 tx(onAdvertisingSetStarted txPower)를 붙인다. 사이클 배지가 추가됐다. TTL과 송신 레벨 입력이 추가됐다(송신 레벨은 dBm, AdvertisingSetParameters −127..1). 저장·공유 버튼이 ①에 있다(FileProvider). 31+ 폰에서 권한이 없으면 빨간 줄과 "허용" 버튼이 배지 아래 나온다.
사이클 줄은 ① 안N·OFF·ON·실행. OFF+ON<60이면 경고(손님 앱 재전송 억제 15분과 겹치지 않도록). 실행 중에는 입력 대신 진행 줄(CYCLE k/N·남은 초·막대·중단). OFF/ON은 enableAdvertising이라 주소가 안 바뀐다(D-005). 끝나면 세 파일 자동 저장.
raw Flags는 점선앱이 넣는 건 27B. Flags 3B는 스택이 넣고 값(0x06/0x1A)이 기기마다 다르다(D-006). 목록에 표시는 하되 점선으로 "앱 바깥"임을 보인다.
카운터에 주소 회전RPA 회전은 OS가 한다(≈15분, D-004). 앱은 own address를 못 읽으므로 이 값은 손님 앱 CSV pos_addr로 P2에서 채운다 — 구현 1차에서는 숨김.
상태 배지는 콜백에서만 바뀐다"시작"을 눌러도 onAdvertisingSetStarted 전까지 배지는 전환 중. 광고·GATT·사이클 배지는 서로 독립. 오류는 배지·ERR 로그·스낵바 3곳(FR-20).
Activity Log 줄은 시뮬레이터와 같은 포맷HH:mm:ss.SSS CAT sid msg. pair_logs.py가 읽는다. Android 전용 줄: MTU 185, result notify 구독, publisher started (AdvertisingSet 콜백 확인), CYCLE k/N stop|start.
지우기는 로그 1행수신 이벤트 지우기 → Activity Log에 EVENTS cleared N rows. Activity Log 자체는 지우지 않는다(2000줄 링).
디버그 카드는 DEBUG 빌드에만D-009 토글 6종 + 자동 저장. 접혀 있다. 릴리스에는 섹션 자체가 없다(NFR-4).
